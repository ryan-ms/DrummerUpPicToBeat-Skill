# 鼓譜文字格線（tab JSON）格式

這是 `scripts/build_pattern.py` 的輸入格式：用「一個字元 = 一格」的文字畫出每個小節，
script 會負責算格數、補齊所有樂器、轉成 DrummerUp 的完整 JSON。

## 最外層

| 欄位 | 必填 | 說明 |
|---|---|---|
| `name` | 建議 | 模組名稱（譜面標題） |
| `bpm` | 建議 | 四分音符 = 幾 BPM（10–500），譜上沒寫就用 90 |
| `time` | 否 | 預設拍號，例如 `"4/4"`、`"6/8"`，預設 `"4/4"` |
| `grid` | 否 | 預設「每拍幾格」，預設 4 |
| `bars` | 是 | 小節陣列，依譜面順序 |

## 每個小節

```json
{
  "time": "4/4",
  "grid": 4,
  "hihat": "x-x- x-x- x-x- x-x-",
  "snare": "---- X--- ---- X---",
  "kick":  "x--- ---- x-x- ----",
  "sticking": { "snare": "---- R--- ---- L---" },
  "comment": "可寫備註，會被忽略"
}
```

- `time`、`grid` 省略時沿用**上一小節**的設定（第一小節沿用最外層）。
- 沒寫到的樂器 = 整小節休息，不用列出來。
- 空白、`|`、`/` 會被忽略，建議用空白隔開每一拍，方便數格子。
- 每一行的格數必須剛好等於這小節的總格數，不然 script 會報錯並指出是哪一小節哪一行。

### grid：每拍幾格

「拍」是**拍號分母**的音符：4/4 的一拍是四分音符，6/8 的一拍是八分音符。

| 這拍裡最小的音符 | 4/4 等（分母 4）的 grid | 6/8 等（分母 8）的 grid |
|---|---|---|
| 四分音符 | 1 | — |
| 八分音符 | 2 | 1 |
| 十六分音符 | 4 | 2 |
| 三十二分音符 | 8 | 4 |
| 八分三連音 | 3 | — |
| 十六分三連音（六連音） | 6 | 3 |

同一小節各拍不一樣時寫成陣列，例如前三拍八分、第四拍三連音：`"grid": [2, 2, 2, 3]`。
一個小節裡選「夠用的最小值」就好，不要全部都用 16 分，DrummerUp 編輯器格子會太密。

## 樂器名稱

| DrummerUp | 也接受 |
|---|---|
| `crash` | `cr`, `cc` |
| `ride` | `rd`, `rc` |
| `hihat` | `hh`, `hi-hat` |
| `tom1`（高音 Tom） | `t1`, `ht` |
| `tom2`（中音 Tom） | `t2`, `mt` |
| `tom3`（落地鼓 Floor Tom） | `t3`, `ft` |
| `snare` | `sn`, `sd` |
| `kick` | `bd`, `bass` |
| `hihatFoot`（腳踩 Hi-Hat） | `hf`, `hhf`, `pedal` |

只有這 9 種。譜上有第 4 顆 Tom、Splash、China、Cowbell 等，就對應到最接近的一軌
（第 4 顆 Tom → `tom3`；Splash/China → `crash`；Cowbell → `ride` 加 `b`），並在回覆中告知使用者。

## 符號

| 符號 | 意思 | 限用 |
|---|---|---|
| `-` 或 `.` | 休息 | |
| `x` | 一般音 | |
| `X` | 重音（accent `>`） | |
| `g` | Ghost note（括號音符） | |
| `o` / `O` | 開踩 Hi-Hat（一般/重音） | `hihat` |
| `b` / `B` | Ride Bell（一般/重音） | `ride` |
| `r` / `R` | 鼓邊／Cross-stick（一般/重音） | `snare` `tom1` `tom2` `tom3` |
| `f` / `F` | 前面帶裝飾音（Flam/Drag，一般/重音） | 任何樂器 |

一格只能有一種符號，所以「開踩 + ghost」這種組合沒辦法表示，取主要的那個。

## sticking：手順

物件，key 是樂器，值是跟音符那一行**等長**的字串，只能用 `R`、`L`、`-`。
只能標在有音符的格子上。譜上沒有手順就整個省略。

## 其他

- `"muteMetronome": true`：這小節節拍器靜音（很少用到）。
- 超過 30 小節會自動拆成多個檔案（`名稱-1.json`、`名稱-2.json`…），因為 DrummerUp 一個模組最多 30 小節。
