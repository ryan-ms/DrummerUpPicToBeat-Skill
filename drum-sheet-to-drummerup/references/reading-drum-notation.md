# 讀鼓譜：五線譜位置 → DrummerUp 樂器

**先找譜面上的圖例（drum key / legend）**。很多出版社會在第一頁標示每個位置是哪個樂器，
有圖例就以圖例為準，下表只是沒有圖例時的預設（跟 DrummerUp 自己印出的樂譜一致，也是最常見的 PAS 慣例）。

五線譜由下往上：第 1 線 (E4)、第 1 間 (F4)、第 2 線 (G4)、第 2 間 (A4)、第 3 線 (B4)、
第 3 間 (C5)、第 4 線 (D5)、第 4 間 (E5)、第 5 線 (F5)，再往上是譜表外。

| 位置 | 符頭 | 樂器 |
|---|---|---|
| 第 5 線上方加線（A5） | ✕ | `crash` |
| 第 5 線上方的間（G5） | ✕ | `hihat` |
| 同上 + 符頭上方 `o` 或圈起來的 ✕ | ✕ | `hihat` 用 `o`（開踩） |
| 同上 + 符頭上方 `+` | ✕ | `hihat` 用 `x`（閉踩） |
| 第 5 線（F5） | ✕ | `ride` |
| 第 5 線（F5） | ◇ 菱形 | `ride` 用 `b`（Bell） |
| 第 4 間（E5） | ● | `tom1` |
| 第 4 線（D5） | ● | `tom2` |
| 第 3 間（C5） | ● | `snare` |
| 第 3 間（C5） | ✕ 或 ⊗ | `snare` 用 `r`（Cross-stick / 鼓邊） |
| 第 2 間（A4） | ● | `tom3`（Floor Tom） |
| 第 1 間（F4） | ● | `kick` |
| 第 1 線或譜表下方（E4/D4） | ✕ | `hihatFoot` |

常見差異：有些譜 Floor Tom 在第 2 線、Kick 在第 1 線之下、Hi-Hat 在第 5 線（跟 Ride 同位置但不同標記）。
遇到不確定的位置，看那個音符跟誰一起出現（例如 8 分音符穩定一路打的 ✕ 多半是 Hi-Hat 或 Ride），
真的判斷不出來就在回覆裡列出來問使用者，不要默默猜。

## 其他記號

| 記號 | 轉換 |
|---|---|
| `>` 重音 | 大寫 `X`（或 `O`/`B`/`R`/`F`） |
| `( )` 括號符頭 | `g` |
| 小符頭 + 斜線，緊貼主音符前 | 主音符改用 `f` |
| 譜上方的 R / L | `sticking` |
| `3` 括號（三連音） | 那一拍 grid 用 3（或 6） |
| 附點音符 | 只看「打下去的位置」，長度不重要——鼓的音長不會延續 |
| 休止符 | `-` |
| 滾奏 `///`（顫音斜線） | 這個 App 沒有滾奏，展開成那拍最小 grid 的連續音符（例如十六分 `xxxx`），並告知使用者 |
| 反覆記號 `‖: :‖`、`%`（同上一小節） | 預設**照譜面展開**成實際演奏的小節；使用者要求「只轉一次」時才不展開 |
| D.S. / D.C. / Coda | 同上，預設展開；小節數超過 30 就讓 script 自動分檔 |
| 速度 `♩ = 120` | `bpm: 120`；`♩. = 80`（6/8 常見）→ 換成四分音符：`bpm = 80 × 1.5 = 120` |

## 鼓的打點位置怎麼數

把每一拍切成 grid 格，看每個音符落在第幾格：

- 4/4、grid 4（十六分）：一拍的四格是 `1 e & a`。
- 8 分音符 + 16 分音符混合時，8 分音符占 2 格，所以 `♪ ♬`（一個八分 + 兩個十六分）= `x-xx`。
- 附點八分 + 十六分 = `x--x`。
- 三連音的三個音各占一格（grid 3）。

上下兩聲部（手在上、腳在下）是同時進行的，要分開數，再對齊到同一個 grid。
